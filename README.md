## 🚀 로컬 실행 방법

로컬 환경에 [Hugo](https://gohugo.io/)가 설치되어 있다면, 아래 명령어로 실시간 편집 서버를 실행할 수 있습니다.

```bash
# 로컬 개발 서버 구동
hugo server
```

서버 구동 후 브라우저에서 `http://localhost:1313`으로 접속해 확인할 수 있습니다.
