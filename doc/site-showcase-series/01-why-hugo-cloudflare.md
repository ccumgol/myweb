# 워드프레스를 버리고 Hugo + Cloudflare로 갔습니다

원래 ccumgol.net에는 워드프레스로 만든 사이트가 돌아가고 있었습니다. 그런데 워드프레스는 관리가 늘 부담이었습니다. 플러그인 업데이트, 보안 취약점, 호스팅 비용, 가끔 느려지는 속도 — 목회하며 틈틈이 돌보기엔 손이 많이 갔습니다.

그래서 이번엔 **정적 홈페이지(static site)** 방식으로 완전히 새로 만들었습니다.

## 정적 홈페이지가 뭔가요?

워드프레스는 방문자가 들어올 때마다 서버가 "그때그때" 페이지를 계산해서 보여줍니다(동적). 반면 정적 홈페이지는 **미리 만들어 둔 HTML 파일을 그대로 내보내는** 방식입니다. 마치 인쇄해 둔 책을 펼쳐 보여주는 것과 같습니다.

- 서버에서 계산할 게 없으니 **매우 빠릅니다.**
- 데이터베이스가 없으니 **해킹당할 구멍이 거의 없습니다.**
- 파일만 올려두면 되니 **호스팅이 사실상 무료입니다.**

## 세 가지 도구의 조합

**Hugo** — 마크다운으로 글을 쓰면 예쁜 HTML 사이트로 변환해 주는 도구입니다. 글쓰기는 워드처럼, 결과는 전문 웹사이트처럼.

**GitHub** — 만든 파일을 보관하는 창고이자 백업입니다.

**Cloudflare Pages** — GitHub 창고를 지켜보다가, 새 글을 올리면 **자동으로 홈페이지를 다시 만들어 배포**합니다. 전 세계 어디서든 빠르게 열리고, 무료입니다.

정리하면: **글을 써서 GitHub에 올린다 → 몇 초 뒤 ccumgol.net이 자동으로 갱신된다.** 서버 관리라는 개념 자체가 사라졌습니다.

## AI는 여기서 무엇을 했나

솔직히 이 구조를 저 혼자 세팅하긴 어려웠습니다. AI가 한 일:

- 도메인을 워드프레스에서 새 사이트로 **안전하게 이전**(기존 설정을 기록해 두어 언제든 되돌릴 수 있게)
- 배포가 실패할 때 로그를 읽고 **원인을 진단**(예: Hugo 버전이 안 맞아 빌드 실패 → 환경변수 한 줄로 해결)
- 그 모든 과정을 **초보자용 매뉴얼로 문서화**

## 무엇이 좋아졌나

| | 이전(워드프레스) | 지금(Hugo+Cloudflare) |
|---|---|---|
| 속도 | 보통 | 매우 빠름 |
| 보안 | 신경 써야 함 | 걱정 거의 없음 |
| 비용 | 호스팅비 | 사실상 무료 |
| 관리 | 업데이트 부담 | 글만 쓰면 끝 |

다음 글에서는, 이렇게 만든 그릇에 **첫 콘텐츠(성경공부 자료)를 담은 이야기**를 나누겠습니다.
