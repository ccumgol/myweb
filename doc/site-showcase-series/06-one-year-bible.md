# 일년일독성경 — 데이터를 문서로, 그리고 CGN 방송과 대조하기

[일년일독성경](https://ccumgol.net/one-year-bible/)은 1년 동안 성경 전체를 1독하도록 돕는 **월별 읽기표**입니다. 1월부터 12월까지, 매일 읽을 분량과 **개역개정 본문 바로가기 링크**가 표로 정리돼 있습니다.

## 1월만 손으로, 나머지는 자동으로

처음엔 1월 읽기표만 손으로 만들었습니다. 2~12월까지 남은 11개월을 똑같이 만들려니 막막했죠. 각 날마다 "창세기 1~3장" 같은 본문을 적고, 장마다 성경 사이트 링크를 거는 작업을 **334일치** 반복해야 하니까요.

그래서 접근을 3편의 동전 도감과 똑같이 했습니다 — **"손으로"가 아니라 "데이터에서 자동으로."**

1. 노션에 정리해 둔 월별 성경본문 데이터를 **그대로 읽어옴**
2. 각 날의 "책 이름 + 장 범위"를 해석
3. 대한성서공회(bskorea) **개역개정 장별 링크를 자동 생성**
4. 1월과 똑같은 표 서식으로 **11개월치 문서를 한 번에** 생성

시편은 '장'이 아니라 '편'으로, 한 날에 여러 책이 겹치는 경우(예: 디도서+빌레몬서)까지 규칙으로 처리했습니다. 결과적으로 **365일이 창세기부터 요한계시록까지 빠짐없이** 이어지는지 자동으로 검증했습니다.

## 목록을 '카드'로

12개월 목록은 밋밋한 글 목록 대신 **카드 형태**로 만들었습니다. 카드마다 '1월'과 그 달에 읽는 책('창세기, 출애굽기')이 한눈에 보이도록 — 발행일 같은 군더더기는 빼고요.

## 반전: AI로 검증하다가 '원본의 오류'를 찾다

여기서 재미있는 일이 있었습니다. CGN 방송의 **2025년 성경일독 프로젝트**(유튜브, 365일 통독 영상)와 우리 읽기표를 **하루 단위로 전부 대조**해 봤습니다.

- 두 표는 같은 개념(365일 신구약 1독, 같은 책 순서)이지만, **하루에 끊는 분량이 달라** 날짜별 본문은 대부분 다르더군요. "같은 여행, 다른 보폭"이었습니다.
- 그런데 대조하는 과정에서 **우리 표(원본 노션 자료)의 실제 오류 2건**이 드러났습니다:
  - 어느 날 "열왕기하 24~45장" — 열왕기하는 25장까지뿐입니다(오타).
  - 신명기 15~16장이 빠져 있던 구간.

두 곳 모두 바로잡았습니다. 사람 눈으로는 몇 년을 봐도 놓쳤을 오류를, **AI로 외부 자료와 교차 검증**하니 금방 찾았습니다.

## 배운 점

반복 데이터는 자동 생성이 답이고, 더 나아가 **AI는 "만들기"뿐 아니라 "검증하기"에도 강력**합니다. 외부의 믿을 만한 자료와 대조하면 내 자료의 오류까지 잡아냅니다.
