**Typing Warrior** (macOS · Windows · iPadOS) · 시행일 · Effective: 2026-11-01 · 만든 사람 · Developer: 박기현 (Gihyun Park)

## 한국어

Typing Warrior는 **개인정보를 수집하지 않습니다.**

- **이 기기에만 저장하는 것** — 사용자 이름, 화면 언어와 연습 언어, 연습 기록, 진행 위치, 배지, 불러온 글과 성경 파일. 모두 이 기기 안(앱 저장 공간)에만 저장되고, 만든 사람이나 다른 서버로 보내지 않습니다. 앱을 지우거나 **기록 초기화**를 하면 지워집니다.
- **광고 · 분석 · 추적 없음** — 광고, 사용 통계, 오류 보고, 추적 도구를 넣지 않았습니다. 계정도 로그인도 없습니다.
- **인터넷을 쓰는 유일한 기능 — "API.Bible에서 받기"** — 사용자가 직접 실행할 때만 [API.Bible](https://scripture.api.bible)에 접속해 성경 본문을 받습니다. 이때 사용자가 입력한 API 키와 API.Bible의 저작권 이용 보고(FUMS)가 API.Bible로 전송되며, 이 정보는 API.Bible의 [개인정보 처리방침](https://www.americanbible.org/about/privacy-policy)을 따릅니다. API 키는 운영체제의 보안 저장소(macOS·iOS 키체인, Windows 자격 증명 관리자)에 암호화해 이 기기에만 보관합니다.
- **링크** — 소개 화면의 링크(홈페이지, 소스 코드 저장소, 후원)를 누르면 기본 웹 브라우저가 열리며, 그 뒤는 각 사이트의 방침을 따릅니다.
- **어린이** — 연령과 관계없이 개인정보를 수집하지 않습니다.
- **문의** — [ccumgol@gmail.com](mailto:ccumgol@gmail.com?subject=Typing%20Warrior)

방침이 바뀌면 이 문서와 앱의 **소개** 화면에 알립니다.

## English

Typing Warrior **does not collect any personal data.**

- **Stored only on this device** — user names, the interface and practice languages, practice records, reading positions, badges, and the texts and Bible files you import. None of it is sent to the developer or to any other server. Deleting the app, or using **Reset records**, removes it.
- **No ads, analytics or tracking.** There is no account and no sign-in.
- **The only online feature — "Get from API.Bible"** — only when you start it yourself, the app connects to [API.Bible](https://scripture.api.bible) to download Bible text. Your own API key and API.Bible's usage report (FUMS) are sent to API.Bible, under API.Bible's [privacy policy](https://www.americanbible.org/about/privacy-policy). The key is kept encrypted in your operating system's secure storage (the macOS and iOS Keychain, Windows Credential Manager) on this device only.
- **Links** on the About screen open your web browser; those sites have their own policies.
- **Children** — no personal data is collected from anyone, of any age.
- **Contact** — [ccumgol@gmail.com](mailto:ccumgol@gmail.com?subject=Typing%20Warrior)

If this policy changes, the change is noted here and on the app's **About** screen.
